# Política de Privacidade – Canais Dark

Última atualização: 25 de novembro de 2026.

## Quem usa o app

O Canais Dark é um aplicativo pessoal. Ele é usado apenas pelo seu criador. Não é oferecido ao público.

## Quais dados o app acessa

Com a permissão do dono, o app acessa as contas do YouTube (Google) e do TikTok do próprio dono. Ele usa esse acesso apenas para ver os dados dos canais e publicar vídeos neles.

## Como os dados são guardados

Os dados e as chaves de acesso ficam guardados no computador do dono. Eles não são vendidos nem compartilhados com terceiros.

## Uso dos dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

## Como remover o acesso

O acesso pode ser removido a qualquer momento em https://myaccount.google.com/permissions e nas configurações do TikTok.
